# Glosario

-----

**Blazor:** stack para interfaces web interactivas con componentes Razor. ([Modelos de aplicaciones](02-Modelos%20de%20aplicaciones%20ASPNET%20Core.md))

**Endpoint:** unidad ejecutable seleccionada por routing para atender una solicitud. ([Host y pipeline](01-Host%20configuracion%20y%20pipeline%20HTTP.md))

**Host:** proceso que configura servicios, servidor, logging y ciclo de vida de la aplicación. ([Host y pipeline](01-Host%20configuracion%20y%20pipeline%20HTTP.md))

**Middleware:** componente del pipeline que procesa una solicitud antes y después del siguiente componente. ([Host y pipeline](01-Host%20configuracion%20y%20pipeline%20HTTP.md))

**MVC:** patrón que separa modelo, vista y controlador. ([MVC y Razor](03-MVC%20routing%20y%20vistas%20Razor.md))

**Model binding:** conversión de datos HTTP en parámetros u objetos .NET. ([MVC y Razor](03-MVC%20routing%20y%20vistas%20Razor.md))

**Razor:** sintaxis que combina marcado con C# para producir UI web. ([MVC y Razor](03-MVC%20routing%20y%20vistas%20Razor.md))

**Razor Pages:** modelo centrado en páginas para UI renderizada en servidor. ([Modelos de aplicaciones](02-Modelos%20de%20aplicaciones%20ASPNET%20Core.md))

**Routing:** proceso que compara una URL y método HTTP con endpoints registrados. ([MVC y Razor](03-MVC%20routing%20y%20vistas%20Razor.md))

**wwwroot:** raíz pública convencional para activos estáticos. ([Host y pipeline](01-Host%20configuracion%20y%20pipeline%20HTTP.md))
