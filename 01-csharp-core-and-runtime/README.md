## Formato de cada lección

1. En una frase
2. Antes de empezar (requisitos y palabras nuevas)
3. El problema
4. Cómo funciona
5. Ejemplo completo (compila tal cual)
6. Errores comunes (con el código de error del compilador)
7. Según la versión de C#
8. Cuándo sí y cuándo no
9. Resumen en 5 líneas
10. Para profundizar (plegado)
11. En entrevista (junior, semi-senior y preguntas de seguimiento)
12. Práctica (con la solución plegada)
13. Siguiente lección

Versión de referencia: **.NET 10 / C# 14**.
